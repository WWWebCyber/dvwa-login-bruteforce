# DVWA Login Brute-Forcer

Многопоточный скрипт на Python для перебора пароля на форме логина
DVWA (Damn Vulnerable Web Application). Поддерживает CSRF-токен,
сессии и параллельный перебор паролей из списка.

⚠️ Использовать только против своей собственной, локально запущенной
копии DVWA или с явного разрешения владельца. Подбор паролей на
чужих, реальных сайтах без разрешения незаконен и наказуем.

## Требования

- Python 3
- Библиотека `requests` (`pip install requests`)
- Локально запущенная DVWA (например, через Docker:
  `docker run --rm -it -p 80:80 vulnerables/web-dvwa`)
- Уровень безопасности DVWA выставлен на **Low**

## Как это работает

1. Скрипт получает CSRF-токен со страницы логина.
2. Для каждого пароля из списка запускается отдельный поток со своей
   сессией, который пробует войти.
3. Как только один из потоков находит верный пароль, остальные
   потоки прекращают работу.

## Использование

\```
python3 dvwa_bruteforce.py <ссылка> <имя> <файл_паролей>
\```

## Пример:

\```
python3 dvwa_bruteforce.py http://127.0.0.1/login.php admin passwords.txt
\```

Файл с паролями — обычный текстовый файл, один пароль на строку.

## Результат

Скрипт выводит найденный пароль, либо сообщение, что пароль не найден.
